EXECUTIVE SUMMARY
Problem Statement & Proposed Solution
Legacy Challenges
  • Manual Spreadsheets: Tracking thousands of alumni via offline Excel sheets leads to stale, duplicated data.
  • Lost Connections: Graduating students lose contact with their college network and career guidance.
  • No Placement Audit Metrics: Administrative difficulty pulling placement statistics for NBA/NAAC accreditations.
  • Data Security Vulnerabilities: Paper and spreadsheet records lack access controls & 2FA security.
The ARMS Solution
  • Centralized Web Directory: Automated self-registration with institutional admin verification flow.
  • Dynamic Search Engine: Search alumni instantaneously by batch year, branch, company, or city.
  • Jobs & Mentorship Hub: Alumni post jobs; students request structured 1-on-1 mentorship.
  • Automated Reports: Export formatted placement & location metrics to PDF and CSV.
SYSTEM CAPABILITIES
Core Objectives & Project Scope
1. Profile & Portfolio
Alumni & students maintain rich portfolios including CGPA, work history, projects, certifications, and skills.
2. Peer Search Engine
Multi-parameter filter engine enabling fast lookups by graduation year, department, employer, and skills.
3. Jobs & Mentorship
Job/internship postings by alumni with direct application tracking and mentorship connection workflows.
4. Admin Governance
Security verification gate, 2FA auth, security audit logs, announcement broadcasts, and placement stats.

SYSTEM DESIGN
3-Tier System Architecture
Presentation Tier
HTML5 / CSS3 / Vanilla JS

Responsive web interface featuring glassmorphic dashboards, dynamic search tables, and client-side form validations.
Application Logic Tier
PHP 8.2 Engine

Processes session authentication, 2FA/OTP validation, password hashing (bcrypt), and SQL query execution.
Data Storage Tier
MySQL 8.0 RDBMS

Normalized (3NF) relational database persisting users, profiles, events, jobs, messages, and audit logs.
SYSTEM FLOW
Data Flow Diagrams (DFD Level 0 & Level 1)
DFD Level 0 (Context)
  • Alumni Entity: Sends reg info & profile updates → Receives directory results.
  • Student Entity: Sends search queries & mentorship requests → Receives matches.
  • Admin Entity: Sends approval decisions & event posts → Receives audit reports.
DFD Level 1 (Process Breakdown)
  • 1.0 Authentication: Validates credentials & OTP against Users table.
  • 2.0 Profile Management: Updates personal/career fields in Alumni_Profile.
  • 3.0 Search Engine: Queries indexed database columns.
  • 4.0 Event Board: Manages campus event creation & RSVPs.

SECURITY & AUTH
Security Architecture & 2FA Flow
Passwords & 2FA OTP
  • bcrypt Hashing: Passwords encrypted before storing in MySQL. Plaintext passwords are never saved.
  • Time-based OTP: Secondary email/SMS 6-digit OTP verification for login and password resets.
Threat Defense & Auditing
  • Admin Gate: New signups require student ID verification by college admin before account activation.
  • Input Sanitation: Server-side sanitization blocks SQL Injection and Cross-Site Scripting (XSS).
CORE FEATURE
Alumni Directory & Search Engine
Dynamic Multi-Parameter Filter
  • Graduation Batch: Filter alumni by exact year (e.g. 2020, 2022, 2024).
  • Department / Branch: Filter by CSE, IT, Electronics, Mechanical, Civil.
  • Employer Company: Instant search for alumni working at target companies (Google, TCS, Infosys, Microsoft).
  • Location & Skills: Filter by city (Bangalore, Pune, NY) or technical skills (Python, React, AWS).
