# AlumniNet - Alumni & Student Management System

A comprehensive web-based platform connecting students, alumni, and administrators with real-time notifications, job portals, event tracking, mentorship programs, and administrative controls.

## 🚀 Key Features

### 🎓 Student & Alumni Portal
- **Profile & Badging**: Custom profile banners, AlumniNet badges, and profile views.
- **Job & Internship Portal**: View active job postings with clear application deadlines and status tracking.
- **Events & Status System**: Live event updates with dynamic status badges and application end dates.
- **Mentorship Program**: Connect with alumni mentors for career guidance.
- **Notification Hub**: Real-time notifications for job alerts, mentorship requests, and system announcements.

### 🛡️ Admin & Control Center
- **Admin Notification Center**: Dedicated sub-page for administrative alerts, system events, and user activity notifications.
- **User Approvals & Audit Logs**: Full audit logging, user role management, and approval workflows.
- **Announcement Analytics**: Visual analytics and engagement tracking for campus-wide announcements.
- **Enterprise Controls**: Configure system-wide parameters, security helper routines, and notification dispatch rules.

### 🔒 Security & Authentication
- Real-time OTP delivery & 2FA support.
- Role-based access control (Admin, Alumni, Student).
- Password reset and activity history tracking.
